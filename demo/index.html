What the repeat checks establish
Each environment gets two fresh kernels and disposable input copies. Floe checks all within-environment pairs before comparing every reference/candidate pair. Variation or an ambiguous comparison returns an inconclusive result.
A match covers only the selected observations and declared policy. It is not proof of equivalence, determinism, or correctness.

03 / KNOW WHAT YOU ARE TESTING
A focused layer
in your existing workflow.
Use Floe when selected in-memory values, table identity or numerical policies matter to a runtime change. Keep your existing scheduler, notebook editor and environment manager.
Existing tools are often enough
Use nbval or pytest-notebook for displayed-output regression tests. Use assertions for a known invariant. Use pinned runtimes and custom images to reproduce an environment. Floe adds a repeat-checked comparison and reduction workflow around explicit typed observations.
Real execution, bounded claims
These examples run actual pandas 2.3.3 and 3.0.0 in local Python 3.12 kernels. They are original, designed fixtures illustrating documented changes, not an unbiased customer corpus or newly discovered pandas bugs.
A path into Snowflake
The standalone recorder can capture materialized Python results inside an existing notebook. Compare exported captures locally. Native SQL execution and hosted Snowflake runtimes have not been validated; no local emulator is implied.
